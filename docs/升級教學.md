# YouBike 資訊網：API 修復與優化教學

這份文件說明這次改了什麼、為什麼要改，以及**你需要親自完成的步驟**（有些步驟需要你的帳號，我無法代勞）。

---

## 0. 先看結論

| 問題 | 原因 | 解法 |
| --- | --- | --- |
| 網站跳出 **429 Too Many Requests** | ① 一次搜尋送出 5 個以上請求，其中 3 個是「整個縣市的全部資料」；② 每次進頁面都重新申請 token，而且 3 個元件各申請一次；③ 金鑰公開在 GitHub，**任何人都能用你的額度** | 加一層 Cloudflare Worker 代理，負責快取 token 和資料；前端每個縣市只下載一次資料 |
| 金鑰外洩 | `client_secret` 直接寫在前端程式碼，公開 repo 誰都看得到 | 金鑰改存到 Worker 的 Secret，前端完全不碰 |

> **根據 TDX 官方文件，呼叫方式本身沒有改**：認證端點和 `/api/basic/v2/...` 路徑目前仍在官方 API 目錄中。改的是 TDX 從 2024/4/29 起，依「會員方案」限制每把金鑰的呼叫次數（官方說明見 [tdxmotc/SampleCode](https://github.com/tdxmotc/SampleCode)），舊程式的呼叫量太大，所以一直撞到上限。

---

## 1. ⚠️ 第一件事：作廢舊金鑰（一定要做）

舊的 `client_id` / `client_secret` 已經公開在 GitHub 上好幾年。就算現在把程式碼刪掉，**git 歷史紀錄裡還是查得到**，所以唯一的解法是讓它失效。

1. 登入 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/) → 右上角「會員中心」。
2. 找到「API 金鑰」，**刪除**舊的那組金鑰。
3. 按「新增」建立一組新的金鑰，把新的 Client Id 和 Client Secret 記在安全的地方（例如密碼管理器）。
4. **不要**把新金鑰貼到任何程式碼、README 或聊天訊息裡。下一步會把它存進 Cloudflare。

## 2. 部署 Cloudflare Worker（後端代理）

### 2-1. 它在做什麼？

```
舊：瀏覽器 ──(帶著 client_secret)──▶ TDX           ← 金鑰外洩、每個使用者各打各的
新：瀏覽器 ──▶ 你的 Worker ──(金鑰藏在這)──▶ TDX   ← 有快取，多數請求不會打到 TDX
```

Worker 的程式在 [`worker/src/index.js`](../worker/src/index.js)，負責：

- **保管金鑰**：存在 Cloudflare 的 Secret，前端看不到。
- **快取 token**：token 有效 24 小時，不會每次都重新申請（TDX 規定 token 端點每個 IP 每分鐘最多 20 次）。
- **快取資料**：即時車輛 30 秒、站點 1 小時、車道/景點/餐廳 6 小時。同一段時間內所有使用者共用一份，大幅減少打到 TDX 的次數。
- **白名單**：只允許代理 Bike、Cycling、Tourism 三類 API，也只接受你的網站（CORS）呼叫，避免被別人拿去當免費跳板。

### 2-2. 步驟

1. 到 [Cloudflare](https://dash.cloudflare.com/sign-up) 註冊免費帳號（免費方案每天有 10 萬次請求，很夠用）。
2. 在電腦上打開終端機，進到專案的 `worker` 資料夾，安裝套件：

   ```bash
   cd worker
   ```

   ```bash
   npm install
   ```

3. 登入 Cloudflare（會開瀏覽器讓你授權）：

   ```bash
   npx wrangler login
   ```

4. 把**第 1 步建立的新金鑰**存成 Secret（執行後會要你貼上值，畫面上不會顯示）：

   ```bash
   npx wrangler secret put TDX_CLIENT_ID
   ```

   ```bash
   npx wrangler secret put TDX_CLIENT_SECRET
   ```

5. 部署：

   ```bash
   npx wrangler deploy
   ```

   成功後會顯示網址，類似 `https://youbike-tdx-proxy.你的帳號.workers.dev`，**把它記下來**。

6. 測試：在瀏覽器打開下面這個網址（換成你的網址），應該會看到 JSON 資料：

   ```
   https://youbike-tdx-proxy.你的帳號.workers.dev/api/basic/v2/Bike/Station/City/Taipei?$top=1
   ```

   > 如果你的網站不是 `https://bagoyammy6.github.io`，請修改 `worker/wrangler.toml` 裡的 `ALLOWED_ORIGINS` 再重新部署。

## 3. 讓前端改用 Worker

1. 在專案根目錄（和 `package.json` 同一層）新增檔案 `.env.production`，內容如下（換成你的 Worker 網址）：

   ```
   VUE_APP_API_BASE=https://youbike-tdx-proxy.你的帳號.workers.dev
   ```

   本機開發則新增 `.env.local`，內容相同。
   （Worker 網址不是秘密，`.env.production` 可以 commit。範例請看 [`.env.example`](../.env.example)。）

2. 重新打包並部署到 GitHub Pages：

   ```bash
   bash deploy.sh
   ```

3. 驗證：打開網站 → F12 → Network 分頁 → 搜尋一個縣市。你應該會看到：
   - 請求的網域是 `workers.dev`，不再是 `tdx.transportdata.tw`
   - 沒有任何 `token` 請求
   - 回應標頭有 `X-Proxy-Cache: HIT`（命中快取）或 `MISS`（第一次）
   - 換頁時**不會**出現新請求

## 4. 程式碼改了哪些地方

### 4-1. 減少請求量（解決 429 的核心）

| 情境 | 舊版請求數 | 新版請求數 |
| --- | --- | --- |
| 進入頁面 | 2～3 次 token（每個元件各申請一次） | 0 |
| 第一次搜尋某縣市的單車 | 5 次（其中 3 次是整個縣市的全部資料） | 2 次（站點 + 即時車輛） |
| 換頁 | 3 次（其中 1 次是整個縣市的全部資料） | **0**（在前端分頁） |
| 車道距離 / 方向篩選 | 2 次 | **0**（在前端篩選） |
| 再搜尋同一個縣市 | 同上，全部重打 | 0（快取有效期間內） |

實作方式：

- [`src/api/tdx.js`](../src/api/tdx.js)：所有請求的統一出口。內建快取，同時發出的相同請求只會送出一次；遇到 429 會依照 `Retry-After` 等待後重試一次，仍失敗就顯示「請稍等一下再試」。
- [`src/api/queries.js`](../src/api/queries.js)：每個縣市只下載一次完整清單，分頁、關鍵字、距離/方向篩選都在前端處理。並用 `$select` 只拿畫面需要的欄位，回應變小很多。

### 4-2. 修正的 Bug

1. **車輛數可能顯示錯誤**：舊版用陣列的第幾個（index）把「站點」和「即時車輛」配對，但這是兩支不同的 API，順序不保證一樣。現在改用 `StationUID` 配對。
2. **沒檢查 HTTP 狀態碼**：429 或 401 時，錯誤訊息會被當成資料渲染，畫面變成空白或壞掉。現在會顯示錯誤訊息。
3. **還沒拿到 token 就送出請求**：快速按搜尋時，可能因為 token 還沒回來而失敗。現在 token 由 Worker 處理，不會再有這個問題。
4. **重新整理就 404**：GitHub Pages 不支援 history 模式，在 `/Vue/findbike` 按 F5 會 404。改成 hash 模式（`/Vue/#/findbike`）。
5. **記憶體洩漏**：每次進入頁面都會 `addEventListener` 一次，卻從來沒有移除。現在元件卸載時會移除。
6. **關鍵字會帶到另一頁**：在單車頁輸入的站名，切到車道頁還留著，導致「查無資料」。現在換頁時會清空。
7. **定位失敗時 loading 一直轉**：現在會關閉 loading 並提示原因。
8. **特殊字元造成錯誤**：關鍵字輸入 `(` 之類的字元時，舊版的 `new RegExp(keyword)` 會直接拋錯。現在改成純文字比對。
9. **空結果時地圖報錯**：沒有資料時 `fitBounds` 或 `a[0]` 會出錯。現在有防呆。
10. **車道格式不同時起點標記壞掉**：`LineString` 和 `MultiLineString` 兩種格式都能正確處理。

### 4-3. 安全性

- **XSS 防護**：地圖 popup 和關鍵字標色都是把字串當 HTML 插入。現在所有動態內容都先經過 [`escapeHtml`](../src/utils/html.js) 處理。
- **Mapbox token**：已從程式碼移除（GitHub 的 secret scanning 也會阻擋它被 push）。沒有設定時地圖會改用免金鑰的 OpenStreetMap 圖磚。如果想繼續用 Mapbox 的樣式：
  1. 到 [Mapbox 後台](https://account.mapbox.com/access-tokens/) 建立一個新的 public token，並設定 **URL restrictions** 只允許 `https://bagoyammy6.github.io`（舊 token 已經公開，建議刪除）。
  2. 在專案根目錄新增 `.env.production.local`（這個檔案不會被 commit），寫入 `VUE_APP_MAPBOX_TOKEN=pk.你的新token`。
  3. 重新執行 `bash deploy.sh`。

### 4-4. 效能

- 地圖上的站點標記：舊版用雙層迴圈比對（站點數 × 站點數，台北上千個站就是上百萬次比對），改成 `Map` 查表。
- marker 改成批次加入（`addLayers` + `chunkedLoading`），同一種圖示只建立一次。
- 大型清單用 `markRaw`，避免 Vue 對上千筆資料做深層響應式追蹤。

---

## 5. 如果還是遇到 429

1. 確認 F12 裡的請求是打到 `workers.dev`（不是直接打 TDX）。
2. 確認舊金鑰已經刪除。如果沒刪，別人還在用你的額度。
3. 到 TDX 會員中心查看你的方案額度和使用量。如果流量真的很大，可以考慮升級方案，或把 `worker/src/index.js` 裡 `cacheTtlFor` 的快取時間調長。
